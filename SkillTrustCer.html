⚙️ ตั้งค่า Smart Contract Address (สามารถระบุเองได้) ค่าเริ่มต้นถูกโหลดแล้ว

1. ลงทะเบียนหลักสูตร (Create Training Course)

ผู้ดูแลระบบสร้างหลักสูตร รหัสหลักสูตร และรายละเอียดการอบรม

Admin
🏅

2. ออกใบรับรอง (Issue Certificate)

ออกใบรับรองพร้อมรหัสอ้างอิง วันที่ออก ผู้รับ และบันทึก Hash บนเชน

Issuer
🔐

3. เตรียมรหัสหลักฐาน (Store Certificate Hash)

แปลงข้อมูลผู้เรียนเป็นค่า Hash เพื่อปกป้องข้อมูลส่วนบุคคลก่อนขึ้นเชน

PDPA Privacy
🔍

4. ตรวจสอบความถูกต้อง (Verify Certificate)

ค้นหาด้วยรหัสใบรับรอง หรือสแกน QR Code เพื่อตรวจสอบสถานะ

Public / Employer
🚫

5. เพิกถอนใบรับรอง (Revoke Certificate)

ยกเลิกใบรับรองที่ออกผิดพลาดหรือทุจริต โดยยังคงประวัติการออกไว้

Admin / Issuer
🎓

6. แสดงประวัติใบรับรอง (Certificate Dashboard)

ผู้เข้าอบรมเชื่อมต่อ Wallet เพื่อดูรายการใบรับรองที่ผูกกับบัญชีของตน

Trainee Wallet
